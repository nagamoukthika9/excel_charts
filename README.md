# World Happiness Report — Chart Story (2018)

## Project Overview
This project uses the 2018 World Happiness Report dataset to turn country-level happiness scores into a simple visual story using Microsoft Excel.

## Charts Created
1. **Top 10 Happiest Countries:** Compares the happiness scores of the top-ranked countries.
2. **Bottom 10 Happiest Countries:** Highlights the lowest-ranked countries in the dataset.
3. **Line Chart:** Shows the happiness scores of the top 10 countries.
4. **Pie Chart:** Shows the distribution of the top 10 countries across three happiness-score categories.

## Key Insights
- Finland ranked first with a happiness score of 7.632.
- The top 10 countries had scores ranging from 7.272 to 7.632.
- Three countries scored 7.5 or above, while seven scored between 7.0 and 7.5.

## Tools Used
- Microsoft Excel
- World Happiness Report 2018 dataset

## Conclusion
The charts make it easier to compare happiness scores, identify rankings, and communicate the main findings clearly.
